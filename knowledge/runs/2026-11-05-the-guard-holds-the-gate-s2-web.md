## Decided

- **The speech shows for answer-to-your-line too.** The same rule draws the line above the speaker for an answer to the viewer's own line. One speech rule serves both, rather than a guard who speaks on a bump but not when he is spoken to — [speechAtSpeakers.ts](https://github.com/KirkDiggler/rpg-dnd5e-web/blob/2986103b3b24c7bc5bae5631c824ef96a3adabb9/src/components/session/combat-experience/speechAtSpeakers.ts).
- **The speech lives as long as its notice.** It is derived from the notices on screen, not timed again, so dismissing the notice removes the speech — [CombatExperience.tsx](https://github.com/KirkDiggler/rpg-dnd5e-web/blob/2986103b3b24c7bc5bae5631c824ef96a3adabb9/src/components/session/combat-experience/CombatExperience.tsx).
- **`barred` is scoped like `heard`,** as design R2 A says. Encounter T6 was not pushed when this was built. If its `MachineBeatScoped` leaves `barred` out, the studio's `within` list must follow — [creatureStates.ts](https://github.com/KirkDiggler/rpg-dnd5e-web/blob/2986103b3b24c7bc5bae5631c824ef96a3adabb9/src/concepts/world-building/creatureStates.ts).

## Found

- **The studio refused `on: barred`.** The lead's note expected the carry rule to import it. The `on` word is checked against `STATE_BEATS`, not carried, so the served castle would have failed to import once T9 lands — [creatureStates.ts](https://github.com/KirkDiggler/rpg-dnd5e-web/blob/2986103b3b24c7bc5bae5631c824ef96a3adabb9/src/concepts/world-building/creatureStates.ts).
- **The web had no speech at a speaker before this.** A table answer's `say` reached the player only as a notice, plus an animation cue when the row authored one — [sayActivityPresentation.ts](https://github.com/KirkDiggler/rpg-dnd5e-web/blob/2986103b3b24c7bc5bae5631c824ef96a3adabb9/src/npc-activities/sayActivityPresentation.ts).
- **The tests catch mutants.** Removing `barred` from `STATE_BEATS` fails the studio round trip. Turning off the bump toast fails three story and render tests — [bumpStory.test.ts](https://github.com/KirkDiggler/rpg-dnd5e-web/blob/2986103b3b24c7bc5bae5631c824ef96a3adabb9/src/components/session/combat-experience/bumpStory.test.ts).
