# Decisions — the repo root

One line per entry, dated and linked. Ingest is the writer; entries arrive through its reviewed PR.
A decision reads `- <date> · <the words> · options: <the options it closed> · because: <why> · <link> · upheld: <links, or none yet>`;
a finding, friction or open line reads `- <date> · <the words> · <link>`. A finding that needs more than a line links its case file in `findings/`.
Friction names both entries and never settles them.

- 2026-10-30 · the Read back of a creature's actions says each add and drop and what it fights with in the session's order, from the draft alone: with no `actions:` at any layer it says "the kind's weapons" and an add reads "on top of the kind's weapons", never guessing the rulebook base's list, and an add of a weapon the list already holds reads "another javelin"; text typed in Add action or Drop action but not added makes the cast form's Apply refuse, naming the text and focusing the field, and Cancel clears it · options: reading the rulebook base's list into the Read back; Apply discarding unadded text · because: the draft is all the studio holds, and review on #1353 caught the Read back saying "a javelin the kind does not" for a captain who already carries one · [rpg-dnd5e-web#1353](https://github.com/KirkDiggler/rpg-dnd5e-web/pull/1353) · upheld: none yet
