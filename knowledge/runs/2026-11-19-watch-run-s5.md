## Decided

- The map (rooms, walls) comes from the open draft. The snapshot carries only a hash of regions and walls, so a changed map is said, not redrawn: the Layout viewport is the editor's and is bound to the open document — [rpg-project#1013](https://github.com/KirkDiggler/rpg-project/issues/1013).
- The capture reader takes a `kind:"run"` line as the header instead of refusing it. Status lines that say `history_complete: true` no longer add the "earlier history is not implied" warnings; rpg-api never sets it true, so its captures read as before — [0c3b2980](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/0c3b2980).
- The read-back excerpt keeps each routine group's head and `routine*` statements, plus every `creature.routine`, `creature.post` and `creature.blocking` in one group about nothing. That is what `machineOf` and `machinesRunBy` read, and a test checks the drawings come out the same — [d98e5eae](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/d98e5eae).
- A save never writes an incomplete read as complete. A record that restarts under the read is read again from the start at most 3 more times. A `more` page that brings nothing new is retried up to 3 times. After that the save fails and nothing is written. A file missing beats says so in its header, and both the panel and the replay say so too — [review](https://github.com/KirkDiggler/rpg-dnd5e-web/pull/1458#pullrequestreview-5970139712).
- The draft-changed note also catches a creature that now runs a different routine. A run saved from another encounter is named instead ("This run was saved from <name>"), compared by key, or by name when either key is empty. Close puts back the home, view, site operation and inspector state the studio had before the file opened — [review](https://github.com/KirkDiggler/rpg-dnd5e-web/pull/1458#pullrequestreview-5970139712).
- The fold is not incremental: `foldRun` is still memoised on the rows' identity, which changes once per arriving beat — [0c3b2980](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/0c3b2980).
- The changed-draft check compares the set of creature ids, their start cells, the state ids of the routines they run (`machineOf`), and the map hash — [0c3b2980](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/0c3b2980).
- Open a saved run needs no server and is not dev-gated. It is disabled while a run is being watched, and starting a watch closes an open saved run — [0c3b2980](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/0c3b2980).

## Mistaken

- `readWholeRecord` stopped on an empty `more` page as if it had reached the end, and it looped on a `restarted` page that came after the first one. Its test used a `restarted` reply on a read from the start, which the contract rules out, so the real case went untested. Both cases are now tested with replies the contract allows — [review](https://github.com/KirkDiggler/rpg-dnd5e-web/pull/1458#pullrequestreview-5970139712).
- No test failed if replay took its machine drawings from the open draft. A test now opens the file against an empty read-back, and the mutant fails it — [review](https://github.com/KirkDiggler/rpg-dnd5e-web/pull/1458#pullrequestreview-5970139712).

- The first long-run test moved only the hero, so it passed with or without the ring. It now moves a guard first and checks it keeps that cell past 500 beats, and it fails when the watch's `limit: Infinity` is removed — [d98e5eae](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/d98e5eae).
