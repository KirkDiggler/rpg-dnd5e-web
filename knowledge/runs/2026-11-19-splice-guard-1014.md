# Run — 2026-11-19 — the file writer checks its own output

Bug [rpg-project#1014](https://github.com/KirkDiggler/rpg-project/issues/1014), found in the review of [#1459](https://github.com/KirkDiggler/rpg-dnd5e-web/pull/1459#pullrequestreview-5970549824). Base: `rpg-dnd5e-web` `dev` at [`84789fe2`](https://github.com/KirkDiggler/rpg-dnd5e-web/commit/84789fe2). Branch `splice-guard-1014`.

## Shipped

- **The guard.** `spliceYaml` (`src/concepts/world-building/yamlSplice.ts`) parses the text it is about to return and compares its value with the file's own value with the edit applied (`checkWrite`). Text that does not parse, or reads back differently, throws `UnsafeWriteError`, whose message is the sentence the studio shows: "The studio could not write this change safely, so nothing was changed." plus where.
- **The edit is refused at the commit.** Every room edit goes through `commitRoomDocument` (`WorldBuildingConcept.tsx`). It now calls `assertSourceWritable` (`singleRoomDungeon.ts`) before it keeps the edit: the document is encoded and spliced into the file it was read from. An `UnsafeWriteError` refuses the edit through `rejectEdit`, which shows that sentence on its own. The document, the saved draft and undo stay as they were. Export and publish go through the same guarded splice, so they fail closed too.
- **Compact lists take every edit.** A list that starts on its parent's dash (`- - 3`, the castle's ground-paint runs) is handled in `walkSeq` for move, add, remove and edit. Its first remaining row takes the shared line. Every other byte is kept.
- **The castle probe** (`yamlSpliceCastleProbe.test.ts`) walks every list in the served castle.

## Decided

- **The comparison rule.** The guard checks list order, every key, every scalar and its type (`3` is not `"3"`; `null` is not a missing key). It ignores key order, comments, quoting and flow versus block. Because: the engine's decoder and the studio's read maps by key and lists by position. The intended value is `mergeValue(own, base, current)`, so keys the studio does not author must survive too.
- **The guard sits inside `spliceYaml`.** No caller can splice without it. The commit check reuses the export encoder, so there is one write path, not a second copy of it.
- **Only `UnsafeWriteError` refuses a commit.** The commit path allows incomplete policy drafts, which the encoder refuses. Those refusals stay with export and publish, as before.
- **Fallback.** A compact list is rewritten whole from its own value, in block style at its own column, only when a comment line sits in the text the shared line would absorb, or when a later row does not start its own line. The formatting change stays inside that list, and the guard checks the value.
- **Cost.** About 143 ms per committed edit on the 3,317-line castle: the guard's parse is about 54 ms, and the rest is the encoder. The source is parsed once and kept (four files at most). The encoder keeps its last checked write, so the publish panel's encode of the same document right after a commit takes about 25 ms more instead of about 145 ms.

## Found

- **On `dev`, 33 writes failed, all in the courtyard's ground paint** (`room.room.regions.1.ground.paint.0.cells.{1,3,5,6,7,9,11}.q`). They were moves inside a run (unparseable: "A block sequence may not be used as an implicit map key"), and removing or editing a run's first value (wrong value). Runs with two equal values (`[3, 3]`) cannot fail on a swap.
- **The castle-wide probe takes time.** A guarded write costs about 70 ms, so the deep probe (every list's ends removed, added back and edited, about 4,000 writes) takes about six minutes. It runs only with `SPLICE_PROBE=all`. CI runs the moves for every list and the full set for the paint runs, in about 55 s.
- **A key path names YAML keys, not the operator's words.** For example, `room.room.regions[0].cells`. It is good enough for a refusal that should never fire.

## Mistaken

- **The first probe recorded every swap twice**, once as row i down and once as row i + 1 up. They are the same write. Removing the duplicates halved the cost.
- **The concept test anchored the sentence with `$`.** The alert also holds its dismiss button's `×`.
