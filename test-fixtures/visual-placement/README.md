scales, digests, commit ids, paths, and hint ranges are deliberately arithmetic
discriminators and **are not rpg-game-assets provider facts**. They are never
installed under `public/` and never used by Builder or Game. Production data is
accepted only from the exact merged G revision recorded in the tracked provider
